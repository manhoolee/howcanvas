# 快速开始

当前版本依赖后端完成登录、数据保存和 AI 请求代理。开发时需要同时启动 `server/` 与 `web/`，部署时推荐使用根目录 Docker Compose。

## 本地启动

```bash
git clone https://github.com/manhoolee/howcanvas.git
cd howcanvas
cp server/.env.example server/.env
```

编辑 `server/.env` 中的管理员密码。在仓库根目录打开终端 1：

```bash
cd server
npm ci
npm run dev
```

在仓库根目录打开终端 2：

```bash
cd web
bun install
bun run dev
```

启动后访问：

```text
http://localhost:3000
```

## Docker 启动

复制生产配置，替换 `AUTH_SECRET` 和 `ADMIN_PASSWORD` 后启动：

```bash
cp .env.example .env
docker compose up -d --build
```

## 首次使用建议

- 使用环境文件中的管理员账号登录。
- 在「管理后台 -> 渠道与模型」中添加 AI 渠道和模型。
- 登录后的画布、媒体和账户数据由后端保存，浏览器只保留当前账户缓存。

## 说明

- 浏览器保留当前账户缓存；登录时先比较服务器版本，缓存版本一致时不下载完整画布。
- AI API Key 只保存在服务器，浏览器通过同源 `/api/ai` 代理使用渠道。
