- 画布 Agent 结果交付：服务器文本模型返回普通 JSON、Responses SSE 或 Chat Completions SSE 时，画布对话都应显示完整文字和工具调用；只有增量片段的本地 Agent 事件应按顺序合并，最终事件应结束流式状态；Codex 初始化/执行失败应显示真实错误，成功但无文字时应显示明确的无结果提示。上线后请先强制刷新页面再复测；本次发布未主动发起付费模型请求。

- 旧资产迁移容错：服务器已有部分旧资产且浏览器旧资产中至少一项上传失败时，已确认资产应从旧缓存移除，失败项必须继续保留，并在下次登录后重新尝试上传。
- Grok Video V2 渠道：画布和视频创作台提交时，应由服务器专用 Python 3.11 + `aiohttp 3.13.5` 传输栈调用 `/v2/videos/generations`，不包含 `Sec-Fetch-*`；单图参考保持原始提示词，多图参考才添加 `@img1` 至 `@img7`；国内 IP 仅被渠道禁止网页访问时，不应再返回网页形式的 HTTP 451。
- 历史本地污染自愈：nanana 的服务器只有 3 条记录而当前浏览器 IndexedDB 含有其他账号记录时，进入生图工作台后应自动恢复为服务器 3 条，且旧媒体队列不得重新上传。
- 旧页面回写防护：账号 A 已保存的工作台记录 ID 不能通过账号 B 的工作台保存接口写入；服务端应丢弃跨账号 ID，并保留账号 B 自己的记录。
- 工作台账号隔离：账号 A 和账号 B 分别各有一条生图/视频生成记录时，反复使用「更换账号」切换并刷新页面，只能看到当前账号的记录；旧账号日志不得被回写到新账号，切换前已开始的异步任务也不得覆盖新账号界面。
- 安全收紧：新部署默认只显示登录且注册接口返回 403；无对应功能权限的账号不能访问画布、工作台、资产或 AI 能力；服务器渠道生成只扣费一次，上游失败会自动退回额度；超限或类型不匹配的上传应被拒绝。
- 插件与渲染安全：Markdown 中的 `<script>`/危险属性与 SVG 中的脚本、`foreignObject` 不应执行；通过 URL 安装第三方插件必须先出现高风险确认弹窗；页面响应应包含 CSP、`nosniff` 和点击劫持防护头。
- 本地 Agent 凭据：新建的 `~/.infinite-canvas` 目录权限应为 0700，`canvas-agent.json` 应为 0600；升级后旧 localStorage 令牌应自动迁移到当前标签页会话存储。
- 提示词中心布局：页面标题及提示词总数应居中；连续输入搜索文字时应在停止输入约 300ms 后再查询；桌面端分类与标签应在左侧独立滚动，右侧搜索框下直接展示提示词卡片；标签数量较多时不能继续向下挤压提示词，窄屏下应恢复上下排列且内容不溢出；不再显示「我的提示词」Tab，收藏提示词应直接加入我的资产。
- 提示词来源：6 个内置来源应从 Image Prompts 统一仓库读取，更新后数量依次为 323、494、53、76、126、129；提示词仍按 6 个来源分组并可独立启用，来源内可继续按 `tags` 筛选。添加标准 JSON URL 后应能查看内容，填写非数组 JSON 或不可访问地址时应显示失败，并继续保留该来源上一次成功缓存的内容。
- 提示词来源界面：来源应以卡片列表展示，启用开关位于左侧，数量、同步状态和上次成功时间作为次级信息显示，查看、拉取及自定义来源编辑/删除操作使用带文字按钮；底部定时拉取区域应保持独立边框布局。
- 画布提示词库：不应再显示「我的提示词」分组；不展开任何公共来源直接搜索其中的提示词，匹配项应自动显示；点击「插入画布」后应创建正文正确且标题保持为提示词标题的文本节点。
- 全站 Agent：新增 `generation_get_status` 工具，画布生成节点可按 `nodeIds` 查询，生图和视频工作台提交后会返回 `taskId` 并可查询排队、运行、成功或失败状态；需验证查询只由当前活动标签页返回。
- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Codex turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；关闭当前页面后应回退到最近聚焦且仍连接的页面，其他页面回传同一请求结果应被拒绝。
- 本地 Agent 多标签页会话同步：所有标签页共享同一个站点级 Codex 活跃线程；任一页面发送消息、新建、恢复或删除会话后，其他页面应同步活跃线程和聊天记录；Agent 输出仅显示在事件所属线程，运行中不能新建、恢复、删除或再次发送任务。
- 本地 Agent 运行状态同步：在一个标签页运行较长 Codex 任务，等待某张工具卡显示「工具完成」后再打开或刷新第二个标签页；第二个标签页应立即显示 Codex 正在运行并禁用发送，整轮结束后两个标签页同时恢复；工具卡只显示「工具完成」，整轮结束由「本轮完成」表示。
- 本地 Agent 图片附件落画布：在右侧 Agent 上传参考图并要求基于商品信息创建生图流程，附件应创建为保持原比例的真实图片节点，分析提示词应创建为文本节点，二者都应连接到生成配置节点；刷新页面后参考图仍可显示并参与生成。任务中途切换到其他标签页时，附件只能写入发起任务的标签页；若发起标签页关闭，附件读取应失败且不能落入其他画布。
- Agent 对话滚动：从历史或日志切回对话、恢复其他会话时应自动定位到最新消息；手动向上浏览后应显示向下箭头且新消息不强制打断阅读，点击箭头后平滑回到底部并继续跟随新消息。
- Agent 消息区分：用户消息应在右侧以主题浅底气泡显示，AI 回复应在左侧保留 Agent 图标并使用开放式 Markdown 排版；长文本、多张附件、错误消息及浅色/深色主题下均应清晰且不溢出。

## 画布连线、成组与剪贴板操作

- 点击连线后，中部删除按钮可用鼠标点击或键盘 Enter/空格删除当前连线；应只删除目标连线，支持撤销、重做和刷新保存，缩放后仍可点击。
- 右键复制元素时，新元素继承原元素的全部输入、输出连线，原元素及其连线保留；例如 A → B → C 中复制 B，新增 A → B 副本 → C。复制与新增连线应一起撤销、重做并保存；多次复制的节点与连线 ID 应独立。
- 选中一个或多个节点后点击工具栏「组」，会创建包围选区的组并将节点归入组；未选中节点时仍创建空组。
- 画布未处于输入状态时，按 Ctrl/Cmd+V 可将系统剪贴板中的一张或多张图片添加到当前视口中心。
- 点击带有生成 Prompt 的结果卡片时，卡片上方不再显示由 Prompt 派生的标题；弹出的 Prompt 面板应回显完整 Prompt，修改后关闭并再次打开仍保留新内容。
- 对已有文字卡片执行 LLM 润色，或重试文字生成时，结果应只包含最终正文，不应出现分析过程、原文复述、修改说明、“润色后”等前缀、代码围栏或无关上下文。
- 将 Base64 Data URL 图片粘贴、插入或保存到画布时，应正常生成图片节点，控制台不再出现 `fetch(data:image/...)` 被 Content Security Policy 拦截的错误。
