# 画布运行中心

管理员登录后进入 `/admin/monitor`，或从账户后台点击“监控与分析”。普通用户无法访问统计接口和管理操作。

## 页面与图表

| 页面 | 主要内容 | 直观表达 |
|---|---|---|
| 运行总览 | 实时在线、活跃、并发、排队、区间任务与成品 | 指标卡、在线/并发折线、任务结果、模型排行 |
| 生成成功率 | 完整交付、首次、上游、输出和重试挽回率 | 时间趋势、结果堆叠柱图、模型横条、用户×模型热力图 |
| 服务与负荷 | 应用 CPU/RSS/事件循环、宿主机 CPU/内存/磁盘、容器和路由 | 资源曲线、健康状态与采样时间 |
| 用户与在线 | 当前在线、全体/指定用户任务成品、积分和存储 | 用户排行、在线列表、用户明细 |
| 使用与留存 | 活跃、新增、生成用户、首次成功后的再次生成 | 日活趋势、星期×小时热力图、次日/七日留存柱图 |
| 模型与渠道 | 实际调用、生成/查询/取回分离、Token 已测覆盖 | 模型与渠道任务/成功率对比 |
| 任务与交付 | 受理、生成、取回、保存、客户端确认、关联账单 | 结果分布、耗时趋势、任务阶段时间轴 |
| 成品与存储 | 按输出去重的交付数量、字节与时长、用户存储 | 成品环图、产出趋势、用户存储与类型贡献柱图 |
| 积分与对账 | 期初、发放、预扣、实耗、释放、退款、期末及余额差异 | 积分流向柱图、用户消费排行和差异表 |
| 告警与审计 | 当前告警、确认/恢复、HTTP 错误、管理员处置 | 告警卡片、事件时间轴与追踪明细 |

2小时、24小时、7天、30天采用滚动窗口，也可自定义最多366天。页面统一请求一次统计快照，用户、模型、渠道、生成类型可组合筛选，账户类型可区分管理员。实时资源是全站状态；行为和积分仅按用户/账户类型/时间筛选，页面有明确说明。任务列表分页，点任务打开交付时间轴；点击模型/用户排行继续筛选。

## 统计口径

- 完整交付成功率＝成功÷（成功＋失败＋部分成功）。取消、排队、进行中和未知单列。先汇总分子分母，再计算全体成功率；不平均用户百分比。分母不足30显示小样本。
- 图片以服务器保存结果为交付依据；已知预期数量不足则部分成功。视频要求持久媒体哈希和交付时间。文本新调用按响应完整结束记录成功；文本产出不冒充已保存文件。其他仅收到代理响应但未验证成品的调用保留未知交付结果。
- 成品按任务＋输出序号计数，相同哈希的不同输出仍为不同产出。图片张数、视频条数/时长、文本与音频类型分开；素材存量包含上传，与生成成品分开。
- 首次成功和挽回率只统计采集到实际生成尝试的任务。批量中不同输出不是重试。无样本显示“—”，历史未记录的预期数量、重试和流式 Token 不推算。
- 在线为最近90秒有认证心跳且会话仍有效的去重用户；活跃为最近5分钟存在实际交互。多个标签页合并。服务器重启会重建当前在线状态，历史曲线持续保留。
- 时间保存为UTC，界面北京时间。区间左闭右开，按任务受理时间组成任务样本、以最新已同步状态观察；任务状态变化后，过去区间的结果可能更新。资源空桶留空。CSV 包含范围、导出时点、时区和指标版本。
- 积分来自整数微积分分录，期初迁移单列。对账比较每个账户可用、冻结余额与分录总和。供应商采购成本没有数据源时明确未接入，不显示为0。

## 采集与运行

业务 SQLite 的事务触发器写入 `telemetry_outbox`，其中只保留行引用或受限元数据。独立 Worker 每5秒投影到 `analytics.sqlite`，初始化自动回填已有图片任务、账单和积分分录。源库读取使用一致性事务，统计库独立事务保存游标，重播与重启不重复计数。业务服务按15秒记录运行采样，管理页面实时快照5秒、统计30秒更新。在线采集不包含提示词、用户文件内容或渠道凭据。

分析库使用 `canvas-observability` 持久卷；已消费且超过7天的 outbox 分批清理，运行采样保留90天，任务/尝试/积分历史保留。查询最多10万任务，超限要求缩小范围；这限制单次资源占用，并未静默截断总计。Prometheus 独立采集私网 `/internal/metrics`，保留90天/5GB，不开放公网端口，不含用户ID高基数标签。

宿主机每15秒运行只读脚本，读取资源、限定容器状态和画布/API/独立工作台健康检查；后端只挂载脱敏结果目录，不能接触 Docker socket。监控图显示采集时间，采样失联会报警。

## 告警与备份

自动覆盖采集延迟、队列等待超过120秒、磁盘使用超过85%、内存超过90%、服务检查失败、近30分钟成功率低于80%且至少20个结果、积分不一致、超过1小时未结算、备份失败或超过36小时。告警确认和恢复留审计。Prometheus 同时检查后端失联、HTTP错误率与事件循环延迟。

`canvas-backup.timer` 每天北京时间04:20执行在线 SQLite 备份，保存业务库、分析库和账户/渠道元数据；每次用独立副本做完整性恢复验证，保留14份。目录 `/opt/hoosland-archive/canvas-monitor-backups` 为 root 私有。媒体使用本次发布前完整副本；日常数据库备份不等价于每日全量媒体副本。

告警显示在后台，未配置外部通知接收人；本次未向第三方发送消息。供应商成本、供应商配额、外部直连模型结果需要真实数据接口才能纳入。历史在线、资源、访问/留存事件从上线开始积累，无法补造此前30天曲线。持续七天稳定性必须由真实运行观察形成，不将短时回归写成七天验收。容量扩展到超过10万任务单次查询时，按原行动方案引入聚合表和异步大导出。
