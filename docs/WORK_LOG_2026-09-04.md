# 工作日志：Hoosland 站点独立化与 Canvas 生产目录规范化

日期：2026-09-04（北京时间）  
项目：Hoosland / HowCanvas 生产环境  
记录范围：主页入口文案、主页与 Insight 产品树拆分、独立 HTTP 网关、生产目录清理、GitHub 同步和线上验收

## 1. 今日目标

1. 修复主页四个主入口的中英文文案，并防止后续 Canvas 更新将其覆盖。
2. 将主页、Insight 静态站、课程、两套地产工作台、视觉工作台及相关运行资料从 Canvas 生产目录中独立出来。
3. 将全站 HTTP 网关从 Canvas Compose 中拆出，使 Canvas 发布仅管理自身 `app` 和 `backend`。
4. 清理 Canvas 生产目录中的旧站点副本、暂存包、历史网关配置与回滚资料，保留可恢复归档。

## 2. 结果摘要

- 主页入口已固定为：浩瀚画布 / HowCanvas、浩仔乐园 / Hoos OWUI、许愿池 / HoosChat、世界观 / HoosInsight。
- 主页、Insight、全站网关已成为三个独立 Compose 项目；Canvas Compose 仅保留 `app` 和 `backend`。
- Insight 的课程、地产工作台 A/B、视觉工作台、数据、配置和共享 Skill 已收拢至 `/opt/insight`。
- Canvas 根目录已不再包含主页、Insight、课程副本、旧发布暂存、旧网关配置或历史回滚目录。
- 主页、Can、OWUI、Chat、Insight、课程和三套 Insight 工作台均完成 HTTP 200 验收。

## 3. 生产架构

| 入口 | 生产目录 | 部署项目 |
| --- | --- | --- |
| `hoosland.com` | `/opt/hoosland-home` | `hoosland-home` |
| `can.hoosland.com` | `/opt/infinite-canvas` | `infinite-canvas`，仅 `app`、`backend` |
| `owui.hoosland.com` | `/www/openwebui/HOOSWEBUI` | `hooswebui` |
| `chat.hoosland.com` | `/www/flarum/hooschat`、`/www/mysql/flarumdb` | `hooschat`、`flarumdb` |
| `ins.hoosland.com` | `/opt/insight` | `hoosland-insight` 与 Insight systemd 服务 |
| 全站 HTTP 路由 | `/opt/hoosland-gateway` | `hoosland-gateway` |

`hoosland-gateway` 是唯一监听 80 端口的服务。它连接 Canvas、主页、Insight 与 Baota 网络；Canvas 更新不再创建、重建或覆盖主页、Insight 和总网关。

- 主页、Insight、网关容器均为 healthy；Insight 的课程、地产工作台 A/B、视觉工作台服务均为 active/running，重启计数为 0。
- Canvas 根目录当前只保留源码、构建配置、环境文件和 `server-data`；当前 Compose 服务为 `app`、`backend`。

## 7. 过程记录与注意事项

- 首次切换后的旧容器清理命令按顺序执行时，旧网关先被删除，导致入口出现短暂中断。随即用已备份 Compose 重建旧网关并完成恢复，之后采用“新网关通过全部校验后再逐个停止并删除旧容器”的顺序完成切换。
- 当前站点设计为 HTTP，不将 HTTPS 超时视为本次故障。
- Chat 当前连接 `flarumdb`；服务器另有一套 `mysql_hooschat` 容器在运行，未由当前 Chat 使用。该容器未在本次改动中处理，后续需确认是否被其他服务使用。
- `canvas-agent` 为 Canvas Agent 功能源码的一部分；其中的依赖目录未作为旧文件清理。

## 8. 后续规则

1. Canvas 回滚材料统一写入 `/opt/hoosland-archive/canvas-history-<timestamp>/`，不再创建 `/opt/infinite-canvas/backups`。
2. 主页、Insight 和网关分别在各自目录与 Compose 项目中维护。
3. 任何域名路由修改只修改 `/opt/hoosland-gateway/conf.d/hoosland.conf`，先执行 `nginx -t`，再重建网关并验证所有主入口。
4. `server-data/` 为 Canvas 当前持久数据，不纳入常规清理范围。
