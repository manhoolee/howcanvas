# GPT Image 2.5 参数适配

## 实际接口

T8 (`ai.t8star.org`) 的实测调用与 APIPod 文档不完全相同：

- 文生图使用 `POST /v1/images/generations`；图生图使用 `POST /v1/images/edits` 和 multipart 参考图。
- 使用基础模型名 `gpt-image-2.5-flare` 或 `gpt-image-2.5-sunburst`，提交精确的 `size` 或 `auto`。供应商依据像素尺寸选择路由，4K 回包已确认返回 `-4k`，2048 方图回包返回 `-2k`；2048x1152 回包可能仍返回基础模型名，但图片尺寸正确。
- 不发送 APIPod 的 `resolution`。该字段无法保证目标分辨率；使用带 `-4k` 的模型名再传 4K size 会产生 `-4k-4k` 无可用渠道错误。
- `quality` 支持 `auto`、`low`、`medium`、`high`、`xhigh`、`max`，非法枚举返回 400。六档均已实测成功；质量对视觉效果的提升不能只凭状态码量化。
- PNG 透明背景已实测；选择透明背景时低质量不可用，启用时将低质量提升为 medium。
- 单次 `n: 2` 的探测只返回一张。现有画布与工作台逐张创建任务的批量流程继续使用 `n: 1`。

## 菜单与尺寸

- 操作模型列表只显示 Flare、Sunburst；渠道登记保留原始变体。不会向浏览器下发密钥。
- 分辨率、比例和自定义宽高共同编辑同一个 `size`，不新增独立的持久化字段，避免菜单与实际请求不一致。
- 六档质量独立于尺寸，其他图像模型继续使用现有逻辑。
- `auto`、1024x1024、1536x1024、1024x1536、2048x2048、2048x1152、3840x2160、2160x3840 均已验证；自适应输出由模型决定。
- 自定义尺寸两边为 16 的倍数，最大边不超过 3840，宽高比不超过 3:1，总像素在 655360 至 8294400 之间。
- 4K 方图在像素上限内使用 2880x2880。实测请求 4096x4096 也被上游压到这一尺寸，因此菜单不提供超限方图。
